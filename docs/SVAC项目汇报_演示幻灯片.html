项目定位与改造基线

在成熟流媒体框架上做增量扩展，而不是另起炉灶

基线框架
ZLMediaKit —— C++11 高性能运营级流媒体服务框架，原生支持 RTSP / RTMP / HLS / FLV / GB28181 / MP4 / WebRTC / SRT 全协议互通。
改造目标
在不动摇原有协议栈稳定性的前提下，打通 SVAC（GB/T 25724 视频编码）码流的接收与分发链路，接入 GB35114 安全通道处理框架。
改造策略
SVAC 码流采用高效透传方式处理，无需任何第三方依赖即可完成接收、转发、录制与回放，链路轻量、部署简单。

功能实现明细（一）

编解码与协议注册 · RTP 接入与转发

01
编解码与协议注册让 SVAC 成为框架内的一等编解码
  • 编解码枚举新增 CodecSVACV（视频）与 CodecSVACA（音频）
  • RTSP 轨映射新增 SVAC，负载类型 96
  • 新增 SvacTrack 视频轨实现（默认 25fps）
  • 编解码工厂支持按轨道类型自动创建，可直接参与协议转换
src/Extension/Frame.h · src/Rtsp/Rtsp.h · src/Codec/SVACEncoder.{h,cpp}
02
RTP 接入与转发整条 RTP 通道改走 GB35114
  • RTP 接入统一由 GB35114Process 处理，自动识别 TS / PS 负载类型
  • 按 ps_pt / h264_pt / h265_pt / opus_pt 动态建轨，SVAC PS 流原样透传
  • 处理链与现有 GB28181 推拉流流程完全兼容，可复用全部既有接口
  • 转发后可正常转 RTSP / RTMP / HLS / FLV
src/Rtp/GB35114Process.{h,cpp} · src/Rtp/RtpProcess.cpp

功能实现明细（二）

SVAC 录像 · 录像回放

03
SVAC 录像（多路并发切片）同一路流可并发录多份
  • 录制槽位以 file_name 为索引存放于 _manual_slots 映射表，支持多路并发互不干扰
  • 录像数据以「2 字节大端长度前缀 + 原始 RTP 包」写入 .rtp 文件
  • 提供 开始 / 停止 / 状态查询 / 路径获取 四类内部能力
  • 切片结束时广播 kBroadcastRecordSVAC 事件
src/Rtp/RtpProcess.{h,cpp} · src/Common/config.{h,cpp}
04
录像回放（全新实现）按原始时间戳节拍 UDP 回送
  • 解析 .rtp 文件，按 RTP 原始时间戳模拟实时速率逐包回送到目标 UDP 地址
  • 支持 停止 / 暂停 / 恢复 / 快进快退（±秒） / 倍速（0.5 / 1.0 / 1.5 / 2.0）
  • 采用绝对参考时钟，避免定时器漂移累积；变速锚点保证中途变速不跳帧、不追赶
  • 回放结束通过 kBroadcastPlaybackSVAC 上报时长、包数、字节数、结果码
src/Rtp/RtpDumpPlayer.{h,cpp}

功能实现明细（三）

REST API 扩展 · 存储管理与事件回调

05
REST API 扩展10 个新接口，覆盖录像与回放全流程
  • 录像类 2 个、回放类 5 个、存储类 2 个、下载类 1 个
  • 所有接口统一走 CHECK_SECRET() 密钥校验
  • 下载接口做「禁止目录穿越 + 解析后路径必须落在存储根目录内」双重校验
  • 接口文档同步更新至内置 Swagger 页面
server/WebApi.cpp（新增约 900 行） · www/swagger/openapi.json
06
存储管理与事件回调可在线切换录像存储盘
  • 新增存储根目录配置，可枚举各存储盘并返回总量 / 剩余容量（MB）
  • 支持在线切换录像目录，并写回配置文件持久化，重启后生效
  • 新增 WebHook 事件 on_record_svac（切片完成）与 on_playback_svac（回放结束），可直接对接上层视频平台

新增 REST 接口清单

统一前缀 /index/api，均需携带 secret 鉴权，接口文档已同步至内置页面

接口功能说明
recordSVAC按指定文件名开始录像，支持同一路流并发多路录制，重复文件名自动忽略
stopRecordSVAC停止指定文件名的录像；不传文件名则停止全部手动录像
playBackSVAC以录像文件为源发起回放会话（默认 UDP，enable_tcp=1 走 TCP 推流），会话以流名唯一标识
stopPlayBackSVAC停止指定回放会话
pausePlayBackSVAC暂停 / 恢复回放
setPlayBackSpeed设置回放倍速，支持 0.5 / 1.0 / 1.5 / 2.0 四档
seekPlayBackSVAC快进 / 快退指定秒数（正数前进、负数后退）
downloadRecordSVAC下载录像文件，含目录穿越防护与存储根目录边界校验
getStorageList枚举存储根目录下的各存储盘，返回总量与剩余容量
setStoragePath在线切换录像存储目录，并写回配置文件持久化
